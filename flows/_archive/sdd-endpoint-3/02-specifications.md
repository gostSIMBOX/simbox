## Constructor

### Endpoint()

**Purpose**: Initialize Endpoint and subscribe to native events.

**Side Effects**:
- Adds 6 DeviceEventEmitter listeners
- Cannot be removed (no cleanup method exists)

**Implementation**:
```javascript
constructor() {
    super();
    
    DeviceEventEmitter.addListener('TeleCallReceived', this._onCallReceived.bind(this));
    DeviceEventEmitter.addListener('TeleCallChanged', this._onCallChanged.bind(this));
    DeviceEventEmitter.addListener('TeleCallTerminated', this._onCallTerminated.bind(this));
    DeviceEventEmitter.addListener('TeleCallScreenLocked', this._onCallScreenLocked.bind(this));
    DeviceEventEmitter.addListener('TeleMessageReceived', this._onMessageReceived.bind(this));
    DeviceEventEmitter.addListener('TeleConnectivityChanged', this._onConnectivityChanged.bind(this));
}
```

**Known Issue**: Event listeners are never cleaned up, potential memory leak if Endpoint is instantiated multiple times.

## Public Methods

### start(configuration: Object): Promise<Object>

**Purpose**: Initialize the native telephony module.

**Parameters**:
| Name | Type | Required | Description |
|------|------|----------|-------------|
| configuration | Object | Yes | Module configuration |
| configuration.ReplaceDialer | boolean | No | Set app as default dialer |
| configuration.Permissions | boolean | No | Request permissions (currently commented out) |

**Returns**: `Promise<Object>`
- Resolves to: `{ accounts: [], calls: Call[], ...extra }`
- Rejects with: Error data from native module

**Behavior**:
1. If `ReplaceDialer === true`:
   - Creates ReplaceDialer instance
   - Checks if already default dialer
   - If not, attempts to set as default
2. Validates `NativeModules.TeleModule` exists
   - Throws descriptive error if null
3. Calls `NativeModules.TeleModule.start()`
4. On success:
   - Parses accounts array (currently empty)
   - Parses calls array into Call objects
   - Extracts extra properties
   - Resolves with combined object
5. On failure:
   - Rejects with error data

**Error Message** (if TeleModule missing):
```
react-native-tele: NativeModule.TeleModule is null. To fix this issue try these steps:
• Rebuild and re-run the app.
• If you are using CocoaPods on iOS, run `pod install` in the `ios` directory and then rebuild and re-run the app. You may also need to re-open Xcode to get the new pods.
• Check that the library was linked correctly when you used the link command by running through the manual installation instructions in the README.
* If you are getting this error while unit testing you need to mock the native module. Follow the guide in the README.
If none of these fix the issue, please open an issue on the Github repository: https://github.com/telefon-one/react-native-tele
```

## Usage Example

```javascript
import { Endpoint } from 'react-native-tele';

// Initialize
const endpoint = new Endpoint();

try {
    await endpoint.start({ ReplaceDialer: false, Permissions: false });
    console.log('Telephony module started');
} catch (e) {
    console.error('Failed to start:', e);
}

// Subscribe to events
endpoint.on('call_received', (call) => {
    console.log('Incoming call:', call.getRemoteNumber());
});

endpoint.on('call_changed', (call) => {
    console.log('Call state:', call.getState());
});

endpoint.on('call_terminated', (call) => {
    console.log('Call ended');
});

// Make outgoing call
const call = await endpoint.makeCall(1, '1234567890', {}, {});

// Answer incoming call
endpoint.on('call_received', async (call) => {
    await endpoint.answerCall(call);
});

// Hangup
await endpoint.hangupCall(call);

// Hold/Unhold
await endpoint.holdCall(call);
await endpoint.unholdCall(call);

// Mute/Unmute
await endpoint.muteCall(call);
await endpoint.unMuteCall(call);

// Audio routing
await endpoint.useSpeaker(call);
await endpoint.useEarpiece(call);
```

## Known Issues

### Issue 1: Memory Leak Risk
**Problem**: Event listeners added in constructor are never removed.

**Impact**: If Endpoint is instantiated multiple times, old listeners remain active.

**Fix**: Add `destroy()` method:
```javascript
destroy() {
    DeviceEventEmitter.removeAllListeners('TeleCallReceived');
    DeviceEventEmitter.removeAllListeners('TeleCallChanged');
    // ... etc
}
```

### Issue 2: Missing Imports
**Problem**: `_onConnectivityChanged` references `Account` class, `_onMessageReceived` references `Message` class, but neither are imported.

**Impact**: Runtime errors if these events are triggered.

**Fix**: Import Account and Message classes or remove handlers.

### Issue 3: Duplicate Implementations
**Problem**: Both `Endpoint.js` and `tele_endpoint.js` exist with similar functionality.

**Impact**: Confusion about which is primary, maintenance burden.

**Fix**: Deprecate one implementation or merge them.
