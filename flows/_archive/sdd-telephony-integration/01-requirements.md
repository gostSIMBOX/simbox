# Requirements: Telephony Integration

> Functional and technical requirements for integrating recat-native-tele package.

**Status**: DRAFT

**Date**: 2026-03-04

## 1. Overview

This document defines requirements for integrating the `recat-native-tele` v0.0.2 package into the react-native-dialer-replacement application. The integration enables Android dialer functionality with SIP-based audio calling capabilities.

---

## 2. Goals

1. **Enable Audio Calling**: Implement SIP-based audio call functionality
2. **Background Operation**: Maintain call handling when app is backgrounded
3. **Call State Management**: Track and display call states (incoming, active, terminated)
4. **Event-Driven Architecture**: React to call events in real-time

---

## 3. Functional Requirements

### 3.1 Endpoint Initialization

**FR-1**: The system SHALL initialize the telephony endpoint on app start  
**FR-2**: The system SHALL retrieve existing calls/settings from background service  
**FR-3**: The system SHALL handle initialization failures gracefully

### 3.2 Call Management

**FR-4**: The system SHALL support making outgoing calls via `makeCall(destination, options)`  
**FR-5**: The system SHALL support creating SIP accounts via `createAccount()`  
**FR-6**: The system SHALL assign unique IDs to each call for tracking

### 3.3 Event Handling

**FR-7**: The system SHALL subscribe to `call_received` events for incoming calls  
**FR-8**: The system SHALL subscribe to `call_changed` events for state updates  
**FR-9**: The system SHALL subscribe to `call_terminated` events for call cleanup  
**FR-10**: The system SHALL match events to tracked calls by call ID

### 3.4 Background Service

**FR-11**: The system SHALL maintain call handling when JavaScript context is suspended  
**FR-12**: The system SHALL synchronize state when app returns to foreground  
**FR-13**: The system SHALL notify users of incoming calls in background mode

---

## 4. Non-Functional Requirements

### 4.1 Platform Support

**NFR-1**: Support Android only (iOS not required)  
**NFR-2**: Compatible with React Native 0.60+ (AndroidX)  
**NFR-3**: Minimum SDK version: 16  
**NFR-4**: Target SDK version: 28

### 4.2 Performance

**NFR-5**: Call event delivery latency < 500ms  
**NFR-6**: Background service memory footprint < 50MB  
**NFR-7**: App cold start to endpoint ready < 3 seconds

### 4.3 Reliability

**NFR-8**: Handle network connectivity changes during calls  
**NFR-9**: Recover from SIP server disconnections  
**NFR-10**: Maintain call state across app lifecycle transitions

### 4.4 Security

**NFR-11**: Secure SIP credentials storage  
**NFR-12**: Encrypt call signaling (TLS/SRTP support if available)
