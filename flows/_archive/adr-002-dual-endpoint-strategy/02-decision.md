# ADR 002: Dual Endpoint Strategy - Decision

## Decision Statement

**Maintain both Endpoint implementations** with clear documentation distinguishing their use cases:

- **Endpoint.js**: PJSIP-based SIP/VoIP telephony (full-featured)
- **tele_endpoint.js**: Android Telecom cellular calls (basic functionality)

## Rationale

1. **Different Use Cases**: SIP and cellular serve different application requirements
2. **Implementation Complexity**: Merging would create overly complex single class
3. **Backward Compatibility**: Existing applications depend on both
4. **Flexibility**: Developers can choose appropriate implementation

## Compliance

Documentation MUST clarify:
1. Which implementation to use for SIP vs cellular
2. Feature differences between implementations
3. Event naming differences
4. Import paths and class names

## Naming Convention

To reduce confusion, consider renaming:
- `Endpoint.js` → clearly documented as "PJSIP Endpoint"
- `tele_endpoint.js` → clearly documented as "Android Telecom Endpoint"

## Exceptions

None currently documented.
