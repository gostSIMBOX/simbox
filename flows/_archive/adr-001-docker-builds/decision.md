# Decision: Docker-Based Build System

**ADR Reference**: ADR-001

## Summary

Use Docker containers for all PJSIP builds to ensure reproducibility and simplify multi-version support.

## Key Points

1. One Docker image per PJSIP version (2.7.1, 2.9, 2.10)
2. All dependencies bundled in image (NDK, SDK, codecs, build tools)
3. Build workflow: `docker build → docker run → docker cp → docker rm`
4. Multi-architecture: armeabi-v7a, x86, arm64-v8a, x86_64

## Rationale

- Reproducible builds across different host environments
- No host system dependency conflicts
- Parallel PJSIP version support
- Simplified developer onboarding (only Docker required)

## Consequences

**Benefits**:
- Reproducibility
- Isolation
- Version parallelism
- Clean artifact extraction

**Costs**:
- Large image sizes (~2-3GB each)
- Longer build times (no multi-stage optimization)
- Docker requirement for all developers
