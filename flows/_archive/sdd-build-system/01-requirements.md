# Build System Requirements

> Spec-Driven Development: Docker-based PJSIP build system for Android.

## Overview

Build system for compiling PJSIP with codec dependencies (OpenSSL, OpenH264, Opus, G.729) for Android platforms using Docker containerization.

## Stakeholders

- **Build engineers**: Need reproducible, reliable builds
- **Developers**: Need consistent library versions across environments
- **Release managers**: Need versioned, traceable build artifacts

## Goals

1. **Reproducibility**: Same build output regardless of host environment
2. **Multi-version support**: Parallel support for PJSIP 2.7.1, 2.9, 2.10
3. **Multi-architecture**: Build for armeabi-v7a, x86, arm64-v8a, x86_64
4. **Codec integration**: Bundle G.729, G.7221, Opus, OpenH264, OpenSSL
5. **Patch management**: Apply version-specific patches during build

## Non-Goals

- iOS build automation (separate workflow)
- Multi-stage Docker optimization (simplicity over image size)
- Parallel architecture builds (sequential is sufficient)

## Constraints

- Android NDK r12b (fixed version for compatibility)
- Android SDK tools r25.2.5 (legacy API support: 19-29)
- Ubuntu base image (for build environment consistency)
- Docker required on host system

## Success Criteria

- [ ] Build completes without manual intervention
- [ ] Output libraries work across all target architectures
- [ ] Multiple PJSIP versions can be built in parallel
- [ ] Build is reproducible on any Docker-enabled host
