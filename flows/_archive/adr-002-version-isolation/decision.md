# Decision: Version Isolation Strategy

**ADR Reference**: ADR-002

## Summary

Isolate each PJSIP version in separate directories with dedicated Docker images to prevent conflicts and enable independent evolution.

## Key Points

1. Separate build directories: `android_2.7.1/`, `android_2.9/`, `android_2.10/`
2. Separate patch directories: `src/patch_2.7.1/`, `src/patch_2.9/`
3. Separate Docker images: One image per version
4. Separate output: `dist/android_X.Y.Z/` per version

## Rationale

- No version conflicts between PJSIP versions
- Independent evolution of each version
- Clear separation for developers
- Parallel builds possible

## Consequences

**Benefits**:
- Isolation
- Independent evolution
- Clear separation
- Parallel builds

**Costs**:
- Duplication of Dockerfiles/scripts
- Storage overhead (~6-9GB total)
- Maintenance burden across versions
