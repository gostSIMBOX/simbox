> Version: 1.0

## Overview

Визуальные макеты экранов dialer (звонилки) для GOSTsimbox Android Gateway.

**Специфика Gateway SIP↔GSM:**
- Индикация активной линии (SIP/GSM)
- Выбор метода маршрута для каждого звонка
- Статус шлюза (SIP registration, GSM signal)
- Dual-SIM + Dual-Line (SIP + GSM) поддержка

**Экраны:**
1. Dial Pad — набор номера
2. Contacts — контакты
3. Recent Calls — недавние звонки
4. In-Call Screen — экран звонка
5. Line Selection — выбор линии

## Notes

### Cross-References (avoid duplicates)

| Screen | vdd-dialer | vdd-screens | Use |
|--------|-----------|-------------|-----|
| Recent Calls | ✅ Simplified | ✅ Full spec | Use `vdd-screens/calls` |

### Gateway-Specific Features

- **Line Indicators**: 🌐 SIP / 📱 GSM
- **Status Colors**: 🟢 Available / 🟡 Degraded / 🔴 Unavailable
- **Route Display**: Shows call path (SIP→Gateway→GSM or Direct GSM)
- **Cost Estimates**: Real-time cost display based on route
- **Audio Path**: TX/RX meters for both SIP and GSM legs
- **Bridge Status**: Shows both legs for bridged calls

### Bottom Navigation

4 tabs (Contacts, Recents, Dial Pad, Settings)

### Call Buttons

- Green for answer
- Red for end/decline

### Contact Photos

Circular avatars

### Call Duration

MM:SS format, updates every second

### Audio Levels

Real-time TX/RX meters during call

### Default Dialer

Warning banner if not set as default

## Gateway Call Flows

### SIP → GSM Bridge

```
[Dial Pad] → [Select SIP] → [Bridge Init]
    │
    ├─► SIP Leg (incoming)
    │
    └─► GSM Leg (outgoing)
         │
         ▼
    [Bridge Active] ← Audio mixing →
```

### Direct GSM

```
[Dial Pad] → [Select GSM] → [GSM Call]
```

### Auto-Fallback

```
[SIP Unavailable] → [Auto-fallback to GSM] → [Confirm] → [GSM Call]
```
