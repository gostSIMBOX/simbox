# Visual Mockups: Dongle Configuration UI

> Version: 1.1
> Status: DRAFT
> Last Updated: 2026-03-11
> Source: sdd-dongle-* flows

## Overview

Экраны для конфигурации и мониторинга донгла (адаптера) в GOSTsimbox Android Gateway.
Донгл обеспечивает связь между SIP-аудио и физическим/GSM-интерфейсом.

**Ограничение: К телефону может быть подключен только ОДИН донгл.**

### Структура донгла

```
Донгл = Интерфейс + Тип схемы

[Телефон] ──► [Интерфейс] ──► [Тип схемы] ──► [Линия]
```

### Интерфейс (подключение к телефону)

| Интерфейс | Сигнал | Описание |
|-----------|--------|----------|
| USB-C with DAC | Цифровой (UAC) | Внешний DAC в адаптере |
| USB-C Audio Accessory | Аналоговый (SBU pins) | Использует DAC телефона |
| TRRS 3.5mm | Аналоговый | Headset jack |

### Тип схемы (внутри донгла)

| Тип | Описание | Определение по R |
|-----|----------|------------------|
| Differential (4R+1C) | Дифф. сигнал для линии | GND→MIC ~10k, L→GND ~15k |
| Mono Loopback | L+R смешиваются | GND→MIC ~1.8k, L→GND ~100k |
| Stereo Loopback | L и R раздельно | GND→MIC ~1.8k, L→GND ∞ |
| Earphone-to-Mic | Акустическое сопряжение | GND→MIC ~10k, L→GND ∞ |

**Любой тип схемы может быть с любым интерфейсом (кроме USB-C DAC — там схема после DAC чипа).**
