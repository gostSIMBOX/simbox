## Requirements

### Business Requirements

**BR-1: Centralized Configuration**

The system SHALL provide centralized configuration for all components.

**Rationale**: Single source of truth for system settings.

**BR-2: Environment Overrides**

The system SHALL support environment variable overrides.

**Rationale**: Container deployments need env-based configuration.

**BR-3: Sensible Defaults**

The system SHALL provide sensible defaults for all settings.

**Rationale**: System should run with zero configuration.

### Technical Requirements

**TR-1: Type-Safe Config**

Configuration SHALL be strongly typed.

**TR-2: Validation at Load Time**

Configuration SHALL be validated at load time (fail fast).

**TR-3: Environment Prefix**

Environment variables SHALL use SIMHUB_ prefix.

### Non-Functional Requirements

**NFR-1: Zero-Config Default**

System SHALL be fully functional with defaults only (25+ defaults).

**NFR-2: Port Validation**
