## Requirements

### Business Requirements

**BR-1: Structured Logging**

The system SHALL produce structured logs for aggregation.

**Rationale**: ELK/Grafana require machine-parseable logs.

**BR-2: Log Retention**

The system SHALL retain logs with configurable retention policy.

**Rationale**: Compliance and troubleshooting needs.

**BR-3: Consistent Metadata**

All logs SHALL include consistent metadata fields.

**Rationale**: Correlation and filtering in log aggregation.

### Technical Requirements

**TR-1: Log Levels**

The system SHALL support standard log levels.

**Levels**: debug, info, warn, error, fatal, panic

**TR-2: Output Formats**

The system SHALL support JSON and text formats.

**TR-3: File Rotation**

The system SHALL rotate log files automatically.

**TR-4: Global Logger**

The system SHALL provide global logger instance.

### Non-Functional Requirements

**NFR-1: Default Format**

Default log format SHALL be JSON.

**NFR-2: Rotation Settings**

Default rotation: 100MB files, 3 backups, 28 days retention.

**NFR-3: Compression**

Old log files SHALL be gzip compressed.

### DefaultFieldsHook

**Purpose**: Add metadata to every log entry.

**Fields Added**:

| Field | Value | Description |
|-------|-------|-------------|
| service | "simhub" | Service identifier |
| version | "1.0.0" | Service version |
| timestamp | Unix seconds | Numeric timestamp |

**Implementation**:
```go
type DefaultFieldsHook struct {
    Service string
    Version string
}

func (h *DefaultFieldsHook) Fire(entry *logrus.Entry) error {
    entry.Data["service"] = h.Service
    entry.Data["version"] = h.Version
    entry.Data["timestamp"] = time.Now().Unix()
    return nil
}
```

### Rotation Behavior

**Trigger**: File size exceeds MaxSize (100MB)

**Action**:
1. Close current file
2. Rename to `.1` (shift existing backups)
3. Create new file
4. Compress oldest backup if enabled

**Retention**: Files older than MaxAge (28 days) are deleted.
